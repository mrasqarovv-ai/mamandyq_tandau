# Бағыт

**Бағыт** — Қазақстандағы 9–11 сынып оқушылары мен ата-аналарына арналған кәсіби бағдар және жеке білім маршруты платформасы.

Негізгі идея:

> **«Қайда түсемін?» емес — «Қалай жетемін?»**

Бағыт оқушының орнына шешім қабылдамайды. Ол өзін танудан бастап нақты БББ/ЖОО мақсатына дейінгі жолды көрнекі етеді және A/B/C сценарий ұсынады.

## Жаңа логика

### 1. Өзіңді таны
Мақсаты әлі анық емес оқушы кәсіби бағдар сауалнамасынан өтеді:
- қызығушылық;
- қабілет индикаторлары;
- құндылықтар;
- оқу/жұмыс стилі.

### 2. Мақсат таңда
Мақсаты бар оқушы бірден:
- сыныбын;
- мақсаттағы B-тобын;
- мақсаттағы ЖОО-ны;
- қазіргі сынама/ҰБТ балын таңдайды.

### 3. Айырманы көр
Қазіргі нәтиже 2026–2027 жалпы конкурсындағы тарихи көрсеткіштермен салыстырылады. Бұл **түсу ықтималдығы немесе грант кепілдігі емес**, тек тарихи ориентир.

### 4. Жол құр
- **A жоспары** — негізгі БББ + мақсаттағы ЖОО;
- **B жоспары** — сол БББ, балама ЖОО;
- **C жоспары** — сол бейіндік пәндермен ашылатын балама B-топтар.

Әр жаңа сынама нәтижесін прогреске сақтауға болады.

## Қазіргі MVP

- 51 нақты мамандық;
- 109 білім беру бағдарламалары тобы;
- 61 Қазақстан ЖОО-сы;
- 25 Маңғыстау колледжі;
- оқушы және ата-ана режимі;
- kk / ru / en;
- оқушы–ата-ана көзқарасын салыстыру;
- Бағыт AI;
- Supabase арқылы анонимді аналитика және кері байланыс.

## Құпиялылық

Міндетті тіркелу жоқ. Телефон, email, ЖСН, толық мекенжай сияқты байланыс/сезімтал деректер сұралмайды. Аналитика анонимді UUID және өнімдік оқиғаларға негізделген.

## Архитектура

- Frontend: GitHub Pages
- AI proxy: Cloudflare Worker
- AI: OpenAI Responses API + Web Search
- Analytics: Supabase

Frontend-те OpenAI secret/service-role кілттері сақталмайды.

## Жоба позициясы

Бағыт — жай мамандық тесті немесе ҰБТ балымен университет сүзгісі емес. Оның толық логикасы:

**Өзіңді тану → Мақсат → Айырма → Жеке маршрут → Прогресс**
