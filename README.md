# Өрлеу · Олимпиадаға дайындық

5–8-сыныптарға арналған қазақша интерфейсі бар статикалық оқу сайты. Бұрынғы «Бағыт» сайтының орнына жасалды. Нақты тапсырмалар Daryn ресми беттері және сол беттердегі Google Drive бумаларынан алынды. Бұл Daryn орталығының ресми сервисі емес.

## Не жұмыс істейді

- 528 сынып/тіл бойынша құжат жазбасы, 519 бірегей түпнұсқа файл; барлық жазбада толық алынған мәтін мен дереккөз бар.
- Сынып, пән, оқу жылы, кезең, тіл және материал түрі бойынша сүзу; толық мәтіннен іздеу; беттеу.
- Түпнұсқа PDF қарау және PDF/DOCX/DOC/XLSX жүктеу. Суреттер мен формулалар бастапқы файлда сақталған.
- 258 тексеріліп бөлінген сұрақ үшін жеке сұрақ режимі. Бұл бүкіл архивтегі сұрақтардың толық саны емес.
- Сақталғандар, аяқталды белгілері және жеке жазбалар — осы браузердің localStorage жадында. Серверге жіберілмейді.
- Толық мәтіндік Word жинағы, толықтық CSV есебі және құжаттар/қателер туралы JSON есебі.

## Автоматты бағаланатын тесттер және Telegram

Ресми тапсырмалар мен жауап кілттерінен 5 және 6-сынып жаратылыстануына арналған 15 сұрақтық екі жаттығу жасалды. Әр тест — 15 ұпай; 30 минут осы сайттағы жаттығу уақыты. Өзіндік режимде балл браузерде есептеледі. Мұғалімге жіберу режимінде Worker жауаптарды өзі бағалап, оқушы коды мен нәтижені Telegram-ға жеткізеді; режимге оқушы өзі келісім береді.

Сайттың өзіндік тесттері бірден жұмыс істейді. Telegram хабарламалары үшін өз Cloudflare аккаунтыңызда Worker/D1/Turnstile және өз BotFather ботыңызды баптау қажет. [Қадамдық нұсқаулық](DEPLOY_TELEGRAM_KK.md). Құпия токендер `config.js` ішінде сақталмайды.

## Жергілікті іске қосу

Python 3 жеткілікті, Node және API кілттері сайтты іске қосуға қажет емес. Репозиторий түбірінен:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`index.html` файлын `file://` арқылы ашпаңыз: архив HTTP арқылы жүктеледі. GitHub Pages түбірінен немесе жоба ішкі жолынан жұмыс істейді; барлық ішкі сілтеме салыстырмалы. Бұрынғы AI және Supabase тәуелділіктері алынды. `worker/` ішінде Telegram нәтижелеріне арналған жаңа қосымша сервер бар; сайттың өзіндік жаттығуына ол міндетті емес. Ескі сайтты қайта жазатын GitHub Actions сценарийлері де алынды. GitHub Pages `main` тармағының түбірінен жарияланады. Тест нәтижелеріне арналған қосымша Worker туралы [Telegram қосу нұсқаулығын](DEPLOY_TELEGRAM_KK.md) қараңыз.

## Архив пен сапа

Негізгі деректер — `data/archive.json`; түпнұсқалар — `materials/`. Бір PDF бірнеше сынып/тілге арналған болуы мүмкін: 528 жазбаны 528 бірегей файл деп түсінбеңіз. Әр файлдың SHA-256 бақылау сомасы бар. Біріктірілген сыныптар `grades` тізімінде беріледі; қайшы деректерге `extractionIssues` ескертуі қосылған.

Жинақ **толық емес**. 2020–2021, 2021–2022, 2023–2024, 2024–2025 және 2025–2026 материалдары бар. 2022–2023 бумаларының бір бөлігі желілік HTTP 503 қатесімен ашылмады; 2026–2027 тапсырмалары зерттелген бастапқы беттерден табылмады. Бұл «жарияланбаған» деген дәлел емес. Барлық жеті жылдың мәртебесі сайтта ашық көрсетіледі.

Word — алынған мәтіннің жинағы; бастапқы PDF-тегі күрделі формулалардың, кестелер мен диаграммалардың дәл көшірмесі емес. Сол себепті түпнұсқалар да бірге берілген. Ресми жауаптары жоқ тапсырмаларға жауап ойдан қосылмайды. Word-та мазмұнды ашқаннан кейін өрістерді жаңартыңыз. Қараңыз: [толықтық есебі](ARCHIVE_REPORT.md).

## Тексеру

```sh
node --check assets/app.js
node --check assets/quiz.js
python3 -m unittest discover -s tests -v
cd worker
npm ci
npm test
```

Тесттер барлық жарияланған файлдың SHA-256 сомасын, дереккөздерін, архив схемасын және бөлінген сұрақтардың бастапқы мәтінге сәйкестігін тексереді. Playwright арқылы нақты архив, мобильді/desktop көрініс, сүзгілер, мәтін/PDF көрінісі, жазбалар мен белгілердің қайта ашқанда сақталуы тексерілді.

## Архивті жаңарту құралдары

Сайттың өзі тәуелділік орнатуды қажет етпейді. Импорт және Word экспорт құралдары үшін:

```sh
python3 -m venv --system-site-packages /workspace/.daryn-venv
/workspace/.daryn-venv/bin/python -m pip install -r requirements-tools.txt
/workspace/.daryn-venv/bin/python tools/import_daryn.py
/workspace/.daryn-venv/bin/python tools/report_archive.py
/workspace/.daryn-venv/bin/python tools/export_docx.py --archive data/archive.json --output downloads/daryn-archive.docx
```

PDF шығару үшін `pdftotext` немесе `pypdf`; ескі DOC үшін LibreOffice керек. Drive ішкі бумаларын `tools/daryn_drive.py` қарайды. Импорт сәтсіз болса, бұрын алынған жазбалар сақталады. Жаңа метадеректерді, құқықтық қолдану шарттарын және сұрақ шекараларын жариялау алдында тексеріңіз: автоматты жіктеу толық редакторлық тексеруді алмастырмайды. Сұрақтарға автоматты жауап берілмейді.

Қажет желілік домендер: `daryn.kz`, `www.daryn.kz`, `drive.google.com`, `drive.usercontent.google.com`, `docs.google.com`. Қолжетімсіз немесе жеке құжаттарды айналып өту қарастырылмаған. Импорт қатесі — `data/import-report.json`; жарияланған бастапқы жинаудың шешілмеген сұраулары — `data/sources.json`.

Материалдардың авторлығы түпнұсқа иелерінде сақталады. Сайттағы дереккөз сілтемелері мен авторлық белгілерді алып тастамаңыз.
