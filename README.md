# Өрлеу · Қазақстан тарихы

5–8-сынып оқушыларына арналған Қазақстан тарихы бойынша олимпиадаға дайындық сайты. Барлық тапсырма Daryn ресми архивінен және сол беттерде жарияланған Google Drive бумаларынан алынды. Бұл — тәуелсіз оқу жобасы.

## Сайтта не бар

- Тек Қазақстан тарихының 25 түпнұсқа құжаты: 18 тапсырма, 6 жауап кілті, 1 шешім құжаты.
- Қазақша 6 бағаланатын тест: 5 және 6-сыныптар үшін аудандық, облыстық және республикалық кезеңдер.
- Әр тестте 30 ресми сұрақ; алғашқы 15 сұрақ 1 баллдан, келесі 10 сұрақ 2 баллдан, соңғы 5 сұрақ 3 баллдан бағаланады. Ең жоғары нәтиже — 50 балл.
- 180 сұрақтың мәтіні, жауап нұсқалары және кілттері түпнұсқалармен салыстырылған. 60 минут — сайттағы жаттығу уақыты; ресми олимпиаданың ұзақтығы ретінде берілмейді.
- 7–8-сыныптарға арналған нақты тарих құжаттары архивте бар. Сәйкес ресми кілті тексерілмеген құжаттар автоматты тестке айналдырылмайды.
- Толық мәтін, PDF көрінісі, түпнұсқаларды және тек тарих материалдары бар Word жинағын жүктеу.
- Жеке жазбалар, сақталғандар, дайындық белгілері және осы браузердегі тест нәтижелері.

## Іске қосу

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайтты HTTP арқылы ашыңыз. GitHub Pages `main` тармағының түбірінен жарияланады: https://mrasqarovv-ai.github.io/mamandyq_tandau/ . API кілті өзіндік жаттығуға қажет емес.

Telegram арқылы мұғалімге нәтиже жіберу үшін қосымша Worker бапталады. Нұсқаулық: [DEPLOY_TELEGRAM_KK.md](DEPLOY_TELEGRAM_KK.md). Құпия токен `config.js` ішіне жазылмайды. Бот бапталмаған кезде сайт мұғалімге нәтиже жіберілді деп көрсетпейді.

## Дереккөздер мен толықтық

`data/archive.json` және `materials/` тек Қазақстан тарихын қамтиды. Нақты құжаттар 2024–2025 және 2025–2026 оқу жылдарына тиесілі. Қалған жылдар үшін толықтық расталмаған; оларды «жарияланбаған» деп белгілемейміз. Біріктірілген 5–6-сынып жауап кілттері `grades: [5, 6]` түрінде көрсетіледі.

`data/quizzes.json` ішінде жауапсыз сұрақтар, `data/practice-keys.json` ішінде ресми әріптік жауаптар бар. Worker жауабы `tools/build_quiz_bank.py` арқылы дәл осы тексерілген материалдардан құрастырылады. Ресми кілттер оқуға ашық; бұл жүйе жаттығуға арналған.

Word — түпнұсқадан алынған мәтін жинағы. Күрделі орналасу мен суреттерді бастапқы PDF/DOCX құжатынан қараңыз. Авторлық пен дереккөз белгілері сақталған.

## Жариялау алдындағы тексеру

```sh
node --check assets/app.js
node --check assets/quiz.js
python3 -m unittest discover -s tests -v
cd worker
npm ci
npm test
```

Қосымша тарих тексерістері барлық 180 жауапты ресми кілттерден қайта оқиды, бастапқы сұрақтарды, салмақтарды, жария файлдардың құрамын және сервер банкінің сәйкестігін тексереді. Үш жариялау алдындағы тексерістің нақты есебі `HISTORY_VERIFICATION.md` файлына жазылады.

## Материалдарды жаңарту

```sh
python3 -m pip install -r requirements-tools.txt
python3 tools/import_daryn.py
python3 tools/report_archive.py
python3 tools/build_quiz_bank.py
python3 tools/export_docx.py --archive data/archive.json --output downloads/daryn-archive.docx
```

Импорт Қазақстан тарихына жатпайтын файлдарды жария бумасына көшірмейді. Жаңа материалдың пәнін, сыныбын, кезеңін және ресми жауаппен сәйкестігін қолмен растаңыз. Тек содан кейін тестке қосыңыз. Дереккөздердің қолжетімділігіне қарай архив жартылай болуы мүмкін.
